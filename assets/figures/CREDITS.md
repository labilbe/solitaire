# Cartes à figures — crédits et licence

Les douze figures (valet, dame, roi des quatre couleurs) sont les cartes du
**portrait officiel français** (Paris pattern) du jeu **SVG-cards** de **David Bellot**.

- Auteur : David Bellot — <https://www.svg-cards.org/>
- Source des fichiers : Wikimedia Commons, catégorie
  [SVG French portrait card deck](https://commons.wikimedia.org/wiki/Category:SVG_French_portrait_card_deck)
- Licence : **GNU LGPL version 2.1 ou ultérieure** — texte complet dans `LICENSE-LGPL-2.1.txt`

Les fichiers `*_fr.svg` de ce dossier restent sous cette licence et peuvent être remplacés
par une autre version du jeu de cartes. **Modification apportée** : le filet noir intérieur
(tracé `stroke-width="1.5"`) a été rendu invisible (`stroke="none"`) ; le dessin des figures
est inchangé.

Les symboles d'enseigne utilisés pour composer les cartes chiffrées (`src/pips.js`) sont
extraits du même jeu et relèvent donc de la même licence.
